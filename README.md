# ICRA Project

A basic Python project workspace for development and experimentation.

## Project Overview

This project contains the main application entry point in `main.py` and is set up to run inside a Python virtual environment.

## Getting Started

1. Activate the virtual environment:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. Run the application:
   ```powershell
   python main.py
   ```
